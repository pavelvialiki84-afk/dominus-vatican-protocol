## App-specific function contracts

### Canva — CREATIVE PRODUCTION
Inputs: approved synopsis, cover art, live store URL, audience/language, editorial excerpt cleared for marketing.
Outputs: square 1080x1080 social image, vertical 1080x1350 post, 1080x1920 Story/Reels cover, consistent subtitle/CTA variants, accessible alt text, brand guidelines.
Cadence: Mondays, 2–3 draft concepts from approved facts. Localizations EN, DE (only when verified release), RU. FR/IT prelaunch only after approved wording.
Quality checks: original cover intact, Latin spellings verified, no false store claims, readable small-screen typography, image licensing.
Automation permitted: prepare drafts, create and reuse design templates, organize in Canva Marketing Studio. User reviews final exports.

### Metricool — CONTENT PLANNING AND CHANNEL PERFORMANCE
Inputs: Canva-approved creative, editorial copy, connected channels, approved posting schedule.
Outputs: proposed 7-day content calendar with channel/time/format/language, engagement report (reach, comments, saves, clicks only if supported).
Cadence: weekly editorial calendar, periodic analytics after social accounts connected.
Rules: use verified best-time data, no invented performance. Only create for-review drafts if explicitly authorized; NEVER publish or enqueue an auto-publishing post by default.

### OpenSEO — SEARCH DEMAND AND TECHNICAL FINDABILITY
Inputs: official website, EN/DE search phrases, live metadata, Google Search Console property.
Outputs: search clicks/impressions/CTR/position, indexing anomalies, up to 3 actionable site-title/meta/internal-link or landing-page recommendations, keyword/competitor findings with data sources.
Cadence: weekly Monday review; deeper audit monthly on a need basis and with awareness of usage/credits.
Rules: check actual source and account permissions; treat empty GSC data as unavailable; changing public website requires editorial approval except previously authorized targeted link fixes.

### Windsor.ai — CROSS-CHANNEL ATTRIBUTION AND KPI REPORTING
Inputs: selected connected data sources, per-platform IDs and official metric fields.
Outputs: 7-day scorecard: Search Console organic clicks and impressions, GA4 users/sessions/key events if connected, Metricool channel engagement if available separately, ad cost/conversions if connected. Show source, units, period and missing data.
Cadence: weekly Monday review.
Rules: avoid combining overlapping data or summing unique users across platforms, never conflate Amazon sales ranking with sales. No unapproved campaign change.

### GitHub / Publishing Engine — CANONICAL WORK LOG
Inputs: approved release metadata and marketing decisions.
Outputs: change logs, landing-page issue tracking, asset references and release status.
Rules: keep manuscripts and confidential files out of public GitHub.
